# ClickAssist 1.0.1

## Release summary

ClickAssist 1.0.1 is a polish and safety release focused on branding, UI consistency, overlay behavior, target picking, and documentation.

## Added

- Improved target picker experience for selecting click positions.
- Added overlay protection so auto-click actions avoid the floating controls.
- Added clearer app branding and launcher icon assets.

## Improved

- Centralized typography and theme usage across the app.
- Improved dashboard, setup guide, and start button consistency.
- Improved Settings/About release metadata for version 1.0.1.
- Improved documentation and project analysis structure.

## Fixed

- Reduced risk of accidental clicks on overlay controls.
- Improved launcher icon consistency across Android densities.
- Removed the old native splash logo so the Flutter startup/loading screen is the branded loading surface.

## Install notes

- Android may warn before installing APKs from outside the Play Store.
- Install only from trusted local builds or trusted release locations.
- Accessibility and overlay permissions must still be enabled by the user through Android settings.
