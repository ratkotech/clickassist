# Outdated Documentation Archive

This folder contains previous ClickAssist documentation and visual assets kept for reference.

Files here should not be treated as current product documentation. They may describe older UI, branding, overlay behavior, architecture paths, screenshots, or diagrams that no longer match the active codebase.

Current documentation should live outside this folder, primarily in `docs/analysis/README.md`.

The previous monolithic project analysis is archived at `previous-docs/project-analysis.md` because the current documentation is now split into focused analysis files.

Older logo lockup files that are no longer the current app icon source are archived in `branding/`. The current icon source is `design/clickassist-app-icon.png`.
