## Storage convention

When current screenshots are captured, store them here with descriptive lowercase names, for example:

```text
docs/screenshots/dashboard.png
docs/screenshots/setup-guide.png
docs/screenshots/overlay-running.png
docs/screenshots/point-picker-overlay.png
docs/screenshots/confirmed-target-card.png
```

Do not add fabricated screenshots. Screenshots should come from the current app running on a real device or emulator.
